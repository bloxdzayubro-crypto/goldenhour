# Golden Hour (Bloxd.io シェーダー + テクスチャパック)

Bloxd.io 用の、リアルで立体的なシェーダーとテクスチャパック(軽量版つき)。**非公式のファンメイド**。

| ファイル | 内容 |
|---|---|
| `GoldenHour-Shader.zip` | シェーダー(本編、apiVersion 5) |
| `GoldenHour-Shader-Lite.zip` | シェーダー(最小の軽量版。影の計算を呼ばない)。**本編とどちらか 1 つだけ** |
| `GoldenHour-Shader-Mid.zip` | シェーダー(中間版。本編の見た目を、なるべく残して、重い処理だけを外した。影は、軽いブロックの影を 1 回だけ)。 |
| `GoldenHour-Shader-Mid-Precise.zip` | 中間版の、精密な影(プレイヤー・mob も)版。少し重い。 |
| `GoldenHour-Textures-64-All.zip` | テクスチャパック全部入り(約 41 MB)。解凍してできる `GoldenHour-Textures-64-All` フォルダを、テクスチャパックの欄にドロップ |
| `GoldenHour-Textures-Lite.zip` | テクスチャパック軽量版(約 18 MB)。解凍してできる `GoldenHour-Textures-Lite` フォルダをドロップ |

- `shader-source/`・`shader-source-mid/`・`shader-source-lite/` … シェーダーのソース。 本編の先頭に、強さの調整用の値がある。
- `texture-tools/` … UI の CSS と、生成スクリプト。 元の素材(Bloxd の標準テクスチャ・モデル)は、入れていない。

Bloxd.io とは関係ありません。テクスチャ・モデルは、Bloxd.io の標準のテクスチャ・モデルを元に、加工したものです。権利は、それぞれの権利者に帰属します。権利者からの要請があれば、速やかに、取り下げます。使用は、自己責任で。
